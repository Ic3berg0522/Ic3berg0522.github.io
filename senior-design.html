Senior Design project

AI Arcade

Description of project

AI Arcade is a project aimed to help people who cannot code modify their favorite retro game using AI. The project has a terminal where a player can ask AI to make changes to a game (or create a new game entirely) and the AI will code for the user their modification or game and then show the game and let the person play it.

My role

I am responsible for the hardware implementation including 3D printing the arcade machine, wiring to a Raspberry Pi, and helping integrate the AI systems onto the Raspberry Pi.

Skills or knowledge gained

I have learned how AI agents work through usage of the AI editing software and gained teamwork skills by working with 5 other students.
